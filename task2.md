## PHP Classwork:

Build a simple blog page using the PHP and HTML concepts we have covered so far.

The task should include:

- A page that displays a list of blog posts.
- A form that allows a user to submit a new post with a title and content.
- Server-side handling of the submitted form data.
- Validation that required fields are filled in before showing the new post.
- Displaying the submitted posts in a readable format on the page.

Requirements:

1. Create a new PHP file for the blog project.
2. Use HTML to build the layout and a form for creating posts.
3. Use PHP to process the form submission and manage the list of posts.
4. When the form is submitted, show the new post in the blog list.
5. Ensure each post shows its title and content clearly.

Goal:

Create a working blog page that demonstrates your understanding of PHP forms, arrays, and output generation.
