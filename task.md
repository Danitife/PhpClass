
⚙️ String Manipulation & Conditionals

• Task 1: Password Length Validator
Write a script with a variable $password. Use an if/else statement and a string function to check if the password is less than 8 characters. If it is, print "Password too short"; otherwise, print "Password secured".

• Task 2: Shouting Detector
Create a variable $message. Write a conditional statement that checks if the message is written in all uppercase letters. If it is, print "Stop shouting!"; otherwise, print "Thank you for speaking softly".

• Task 3: Username Formatter
Store a raw username in a variable (e.g., "  samuel  "). Use string functions to clean up any extra whitespace and convert the entire name to lowercase. Print the final cleaned username.

🔁 Operators & Ternary Checks

• Task 4: Membership Fee Calculator
Create a boolean variable $isPremium. Use a ternary operator to print the price of a ticket: if they are premium, the price is $20, otherwise it is $50.

• Task 5: Text Concatenation Guard
Create two variables, $greeting and $name. Use a conditional statement to check if $name is empty. If it is not empty, concatenate them to print "Hello, [name]". If it is empty, print "Hello, Guest".

🔧 Functions with Logic & Scope

• Task 6: The Greeting Customizer
Write a function called greetUser($username). Inside the function, check if the username length is greater than 10 characters. If it is, print "Hello, [username]... wow, you have a long name!". Otherwise, just print "Hello, [username]".

• Task 7: Simple Dynamic Calculator
Create a function called mathWizard($num1, $num2, $operation). Use conditional statements (if/else) inside the function to check the $operation parameter. If it is "add", print the sum. If it is "multiply", print the product.

• Task 8: Global Status Checker
Define a global variable $systemStatus = "maintenance". Write a function called checkSystem(). Use the global keyword to fetch the status, and use an if/else statement to print "Site is Offline" if it is under maintenance, or "Site is Live" if it is not.

• Task 9: Age Gate Function
Write a function called verifyAge($age). Inside the function, use a ternary operator to return or print "Access Approved" if the age is 18 or older, and "Access Denied" if they are younger.

• Task 10: Email Domain Standardizer
Write a function called fixEmail($email). Inside the function, force the entire email string to lowercase using a string function. Then, print "Your official email is: [lowercase email]".
